
# Bank Account Simulator

## Project Description

The Bank Account Simulator is a console-based program that allows a user to create a bank account and perform basic banking operations.

## Features

- Create a bank account
- Generate an account number
- Set a 4-digit PIN
- Login using account number and PIN
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Logout
- Exit the program

## Python Concepts Used

- Variables
- Input and output
- Operators
- Type conversion
- Conditional statements
- While loops
- For loops
- Lists
- Dictionaries
- Functions
- Basic module usage (`random`)
- Exception handling using `try` and `except`

## How to Run

Make sure Python is installed, then run:

```bash
python bank_account_simulator.py
```

## Note

This is a basic educational project. It does not use a database, GUI, or real banking services. Account information exists only while the program is running.
