BANK ACCOUNT SIMULATOR
Python 1st Semester Project
1. Introduction
Bank Account Simulator is a simple console-based Python program. The purpose of this project is to demonstrate basic Python programming concepts by creating a small banking system.

2. Objective
The main objective is to create a program where a user can create an account, log in, deposit money, withdraw money, check the balance, and view transaction history.

3. Features
•Create a bank account
•Generate a simple account number
•Set a 4-digit PIN
•Login using account number and PIN
•Deposit money
•Withdraw money
•Check balance
•View transaction history
•Logout and exit

4. Python Concepts Used
•Variables
•Input and output
•Operators
•Type conversion
•if, elif and else statements
•while and for loops
•Lists
•Dictionaries
•Functions
•Basic module usage with random
•try and except for simple input errors

5. Working of the Program
First, the main menu is displayed. The user can create an account, login, or exit. After creating an account, the user can login with the generated account number and PIN. After successful login, the bank menu provides options for deposit, withdrawal, balance checking, and transaction history.

6. Algorithm
1. Start the program.
2. Display the main menu.
3. Create an account when the user selects account creation.
4. Generate an account number and save the account details.
5. Ask the user for account number and PIN during login.
6. If the login details are correct, display the bank menu.
7. Perform deposit, withdrawal, balance, or transaction operations according to the user's choice.
8. Return to the bank menu until the user logs out.
9. Return to the main menu.
10. Exit when the user selects Exit.

7. Limitations
This is an educational beginner-level project. It does not use a database, GUI, online banking service, or permanent data storage. The account data is lost when the program is closed.

8. Conclusion
The Bank Account Simulator demonstrates how basic Python concepts can be combined to create a useful console application. It provides practice with functions, conditions, loops, lists, dictionaries, and user input.
